# Todo App - Full Stack

## Descripción
Aplicación de tareas desarrollada con React, Node.js y MongoDB.
Permite crear, eliminar, completar y filtrar tareas con persistencia en base de datos.

## Tecnologías
- React (Vite)
- Node.js
- Express
- MongoDB (Mongoose)
- Framer Motion

## Instalación

### Backend
cd backend  
npm install  
node server.js  

### Frontend
cd frontend  
npm install  
npm run dev  

## Funcionalidades
- Crear tareas  
- Eliminar tareas  
- Marcar como completadas  
- Filtrar tareas  
- Animaciones  
- Fecha de creación
